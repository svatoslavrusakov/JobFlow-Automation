# Работа с интерфейсом

Код интерфейса собран в `Scripts/ui/`; общие настройки — в `Scripts/core/`. Запуск через `Scripts/gui.py`, кнопки и настройки сохранены.

[Краткий запуск](../README.md) · [Карта кода](architecture.md)

На вкладке «Сайты компаний»: «Сохранить HTML сайтов» собирает снимки,
«Распознать HTML сайтов» создаёт `vacancy.json`, «Подготовить письма сайтов» — `draft.json`.
Два локальных ИИ-этапа используют лимит, модель и папку из настроек; номера строк и даты игнорируются.
Google Таблица при распознавании и подготовке локальных писем не используется.
«Импортировать результаты» добавляет готовые JSON в выбранный лист без вызова модели. [Порядок проверки](company_vacancies.md).

Все команды выполняются из корня проекта.

## Окно программы

Для запуска интерфейса из корня проекта:

```powershell
.\.venv\Scripts\python.exe -X utf8 Scripts\gui.py
```

Начальный размер окна учитывает размер экрана. В разделах «hh → Этапы», «Сайты компаний», «Telegram», «Настройки» и «hh → Экранный режим» справа
есть внешняя полоса прокрутки: в небольшом окне она позволяет добраться до журнала и кнопки сохранения.
Колесо над подписями, кнопками и полями прокручивает вкладку. Внутри журнала, таблицы или списка
моделей сохраняется собственная прокрутка элемента. Окно можно уменьшать по высоте до 450 пикселей.

В окне пять вкладок:

- **hh** — этапы сбора, ИИ, отправки и проверки ответов; предпросмотр и редактор писем.
  Здесь же отдельная вложенная вкладка «Экранный режим» с настройкой образцов и отправкой через мышь и клавиатуру.
- **Сайты компаний** — сохранение HTML, распознавание, подготовка письма и импорт результатов в отдельный лист. Отправка пока вручную.
- **Telegram** — импорт JSON-экспорта канала, распознавание постов, письма и импорт в отдельный лист;
  обработчики общие с сайтами компаний, папка сообщений отдельная. [Порядок проверки](telegram.md).
- **Настройки** — подключения Google/Chrome/Gemini, модель, пути к файлам, поиск и интервалы.
  Кнопка «Сохранить настройки» записывает параметры для следующих запусков, включая консольные.
- **Колонки таблицы** — чтение первой строки, краткая справка и редактирование названий.

Поле «Лист Google Таблицы» общее с редактором колонок. Параметры отбора и журналы hh, компаний и Telegram
независимы: при переключении вкладки сообщения работающего этапа остаются в его журнале.
Имя листа требуется сборщику HTML и импорту результатов; импорт сообщений и файловые ИИ-этапы запускаются и с пустым полем.
Для импорта выберите отдельный лист результатов: имеющиеся ID и полные ссылки пропускаются,
исходные строки только со ссылками не дополняются. Лимит импорта — число новых записей.

Интерфейс запускает те же этапы, что и `Scripts/run.py`. Пока идёт этап или сетевое действие,
настройки и редактор колонок заблокированы. Сетевые проверки выполняются в фоне.
Кнопка «Ссылки из HTML» предложит выбрать файл сохранённой выдачи hh,
«HTML из папки» — папку с несколькими выдачами. Обе сохраняют ID, ссылку, название и компанию.
Кнопка «Отправить отклики» попросит подтвердить реальную отправку работодателям.
«Ключевые слова» использует строку и лимит, заполняя пустые ячейки одноимённой колонки
в основном листе. Аналитика по этим словам выполняется в таблице самостоятельно.
[Описание этапа](competencies.md).

Работает только один этап за раз. Его сообщения видны в журнале; окно остаётся отзывчивым.
«Остановить после текущего действия» просит программу завершиться перед следующей строкой или во
время паузы между строками. Ожидание ответа Google, ИИ или браузера может занять время; завершённый
клик отправки нельзя отменить кнопкой остановки. После прерывания отправки проверьте последнюю
вакансию на hh и в таблице перед повтором. Коды завершения показаны в журнале.

Для прежних команд hh по-прежнему нужен подготовленный Chrome и выключенный вручную VPN; для ИИ нужны
локальные файлы в `data/` и доступ к выбранному провайдеру. На втором компьютере проверьте наличие
Tkinter командой `.\.venv\Scripts\python.exe -m tkinter`.

### Предпросмотр очереди

На вкладке «hh → Этапы» выберите этап в поле «Очередь для» и нажмите **«Показать очередь»**.
Доступны заполнение по ссылкам, подготовка и просмотр писем, отправка и проверка ответов.
Используются текущий лист и поля отбора: начальная строка, лимит и даты только для проверки ответов.

Окно показывает номер строки, ID, компанию, название, статус, наличие письма и причину пропуска.
Галочка «Показать также пропуски» включает неподходящие строки; «Назад» и «Далее» переключают
страницы по 25 строк. Для проверки ответов дополнительно видна дата последней проверки.
«Обновить очередь» перечитывает таблицу после ручных изменений. Во время загрузки и при ошибке
старые строки очищаются, чтобы их нельзя было принять за новую страницу.

Просмотр только читает Google Таблицу: не открывает hh, не вызывает ИИ и не отправляет отклики.
Для отбора читаются ID, ссылка и статус, а для проверки ответов ещё дата; дополнительные поля
загружаются только для текущей страницы. Полные описания не загружаются.

Правила отбора общие с обработчиками. Для отправки лимит означает число новых подтверждённых откликов,
поэтому список кандидатов может быть длиннее лимита. Кандидат ещё не гарантирует успешную обработку:
состояние hh, авторизация и полные исходные данные проверяются при запуске этапа.
Изменившаяся после чтения строка помечается «Изменена»; обновите очередь.

### Проверить и отредактировать письмо

Выберите «Просмотреть письма» → «Показать очередь». В список попадут `thinking` и `done`;
начальная строка и лимит действуют как обычно. Выберите строку и нажмите «Открыть письмо»
или дважды щёлкните по ней. Письмо можно открыть и из других режимов предпросмотра.

В редакторе рядом с письмом видны описание, специальные требования, риски, зарплата и оценка ИИ.
«Сохранить без одобрения» сохраняет текст со статусом `thinking`.
«Одобрить → done» сохраняет текст со статусом `done` и готовит его для отдельного запуска отправщика.
Редактор не запускает hh или ИИ. Остальные статусы доступны только для чтения.

Перед записью перечитываются ID, ссылка, статус, письмо и показанный контекст. Если они изменились,
сохранение отменяется. Обновляются только письмо и статус; заметки, даты и результаты ИИ сохраняются.
После сетевой ошибки текст остаётся в окне: кнопки записи заблокированы до «Перечитать строку»,
автоматического повтора нет. Перечитывание и закрытие спрашивают об отмене несохранённых правок.
После закрытия редактора очередь обновляется, если была попытка сохранения.

### Колонки таблицы

1. На вкладке «Колонки таблицы» укажите лист и нажмите «Загрузить заголовки».
2. Выберите строку: показываются назначение, кто заполняет колонку и каким этапам она нужна.
3. Для переименования введите новое название и подтвердите действие. Назначение остаётся прежним
   в примечании ячейки Google, поэтому обработчики и другой ПК узнают поле под новым названием.
4. «Добавить» вставляет колонку и заголовок, сдвигая существующие данные.
5. «Удалить заголовок» очищает только первую ячейку колонки после подтверждения. Данные вакансий
   и примечание сохраняются. Для восстановления выберите строку «без заголовка» и переименуйте её.

Удаление обязательного заголовка не удаляет вакансии, но соответствующий этап не запустится
до восстановления. Пользовательские колонки автоматически не заполняются. Обычное переименование
меняет отображаемое имя, а не назначение поля. Исходные примечания пользователя сохраняются.

Шапка и примечания читаются только из первой строки. Обработчики кэшируют назначение до изменения
шапки и сохраняют физические позиции, включая пропуски. Старые листы без примечаний продолжают
работать по прежним названиям. Реальные изменения заголовков в процессе разработки не выполнялись.


## Если файл настроек повреждён

При запуске окно предлагает восстановить стандартные значения. После подтверждения прежний
файл сохраняется рядом с датой и расширением `.bak`. Если запись не удастся, прежний файл
возвращается на место. При отказе программа завершится; настройки можно исправить вручную.
После восстановления проверьте подключения, пути, модель и паузы перед запуском этапов.

Подготовка параметров, выбор входного файла и запуск процесса разделены в `ui/app.py`.
Импорт результатов компаний и Telegram сообщает в журнале, что добавляет только новые записи.
