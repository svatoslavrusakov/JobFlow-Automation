# Auto_hh

Программа собирает вакансии hh, готовит письма через ИИ, отправляет готовые отклики
и проверяет ответы. Google Таблица связывает отдельные этапы; VPN переключается вручную.
На разных компьютерах можно выполнять этапы последовательно. Одновременная обработка
одного листа пока не предусмотрена.

## Быстрый запуск

Нужен Python 3.10 или новее; рабочие версии проекта — 3.11 и 3.13.
Команды PowerShell выполняются из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -X utf8 Scripts\gui.py
```

Если окружение уже есть, создание пропустите. Во вкладке «Настройки» выберите Google Таблицу,
лист и файлы доступа. Подготовка заголовков и подключений описана в [инструкции](Docs/setup.md).
Основная установка уже включает зависимости ИИ и экспорта DOCX. Для экранного режима
дополнительно нужен `requirements-desktop.txt`. Подробности описаны в руководствах ниже.

## Обновление и запуск на старом ПК

Для старого ноутбука с Python 3.11.4 используйте существующую `.venv`.
После слияния нужных изменений в `MainBranch` выполните из корня проекта:

```powershell
git status
git fetch origin
git switch MainBranch
git pull --ff-only origin MainBranch
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -X utf8 Scripts\gui.py
```

Если Git сообщает о локальных изменениях, сохраните их перед переключением ветки.
Активация окружения не требуется: команды обращаются к его Python напрямую.
Локальные настройки и ключи остаются на этом компьютере.

## Chrome для hh

Выключите VPN вручную. Для сценариев Selenium откройте Chrome и войдите в hh:

```powershell
& "C:\Program Files (x86)\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9223 --user-data-dir="$env:LOCALAPPDATA\Auto_hh\ChromeTest" "https://hh.ru"
```

В настройках укажите `127.0.0.1:9223`. Профиль сохраняется между запусками.
Можно использовать кнопку «Открыть Chrome» с сохранёнными настройками.
[Подробности подключения](Docs/setup.md#chrome).

## Обычная последовательность

Сохранённая выдача: **импорт HTML → заполнение вакансий → ИИ → проверка писем → отправка → проверка ответов**.
Живой поиск заменяет первые два этапа. HTML можно импортировать одним файлом или папкой:
в обоих случаях сохраняются ID, ссылка, название и компания. [Команды и статусы](Docs/stages.md).
Отправляются только строки `done` с готовым письмом. Команда отправки делает настоящий отклик.

В окне направления разделены: **hh**, **Сайты компаний**, **Telegram**.
У сайтов компаний последовательность: сохранить HTML → распознать → подготовить письмо → импортировать результат в отдельный лист.
Для Telegram: JSON-экспорт канала → распознавание постов → письма → импорт в отдельный лист.
[Сайты компаний](Docs/company_vacancies.md) · [Telegram и ограничения экспорта](Docs/telegram.md).

Каждый запуск выполняет один этап. Справка консоли:

```powershell
.\.venv\Scripts\python.exe -X utf8 Scripts\run.py --help
```
